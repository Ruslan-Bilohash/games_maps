# games_maps

## too_much — «Двобій 3D» / Duel 3D

Файтинг у браузері на Three.js: кампанія з 7 боїв, 7 бійців, 7 арен, комбо,
супер-удари, фінальний удар, своя музика на кожній карті, мови UA / EN / NO
(меню з прапорами), вхід через email зі збереженням проходження.

- `too_much/` — готова до завантаження на хостинг папка
  (https://bilohash.com/games/too_much/). Інструкція: `too_much/README_UA.md`.
- `src/` — вихідні частини гри і скрипти збірки
  (`build.sh` → `index.html`, `make_hosting.sh` → `too_much/`).

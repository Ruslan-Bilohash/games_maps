# Komiks·Lab World — плоска земля й керування (Unity 6.3, Built-in)

Мінімальна основа: рівна земля, світло, гравець і камера від третьої особи.
Усе створюється у коді при Play — ассети й префаби не потрібні.

## Як запустити

1. Unity Hub: **Add ▸ Add project from disk** → папка `unity/` (редактор `6000.3.11f1`).
2. Дочекайся імпорту.
3. Меню **Comiks ▸ Створити сцену світу** (зберігає `Assets/Scenes/World.unity`).
   Або просто відкрий будь-яку сцену.
4. Натисни **▶ Play**.

## Керування

| Клавіша | Дія |
|---|---|
| WASD | рух |
| Shift | біг |
| Space | стрибок |
| Миша / колесо | камера / зум |
| Esc / клік | відпустити / захопити курсор |

## Файли (`Assets/Scripts/World/`)

- `WorldBuilder.cs` — земля, світло, камера, гравець
- `ThirdPersonController.cs` — ходьба, біг, стрибок
- `OrbitCamera.cs` — камера від третьої особи
- `InputProxy.cs` — ввід (старий Input Manager і Input System)
- `MaterialFactory.cs` — прості матеріали

`.meta`-файли з'являться при першому відкритті в Unity — закоміть їх.

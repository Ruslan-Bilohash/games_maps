# Двобій 3D — встановлення на хостинг

Папка `too_much` — це вся гра. Завантаж її вміст на хостинг так, щоб
вона відкривалась за адресою **https://bilohash.com/games/too_much/**
(локально у тебе це `c:/bilohash/games/too_much`, на сервері зазвичай
`public_html/games/too_much`).

## 1. Що всередині

| Шлях | Що це |
|---|---|
| `index.html` | сама гра (усе в одному файлі) |
| `vendor/three/` | 3D-рушій Three.js r160 (локально, без CDN) |
| `models/` | бійці, анімації, скан голови |
| `api/game.php` | вхід через email і збереження проходження |
| `api/mail_template.php` | гарний лист із кодом і кнопкою входу (UA / EN / NO) |
| `api/config.sample.php` | зразок налаштувань |
| `data/` | тут створиться база SQLite (закрита від браузера) |

Гра працює й **без** налаштування API: бій із комп’ютером, удвох на одній
клавіатурі, проходження (зберігається в браузері). Кнопка «Увійти через
email» з’являється лише тоді, коли API налаштоване.

## 2. Увімкнути вхід через email

1. Скопіюй `api/config.sample.php` → `api/config.php`.
2. У `config.php`:
   - `secret` — довгий випадковий рядок. Згенерувати:
     `php -r "echo bin2hex(random_bytes(32));"` або будь-який генератор паролів (40+ символів).
   - `mail_from` — адреса **на твоєму домені** (наприклад `game@bilohash.com`),
     створи її в панелі хостингу, інакше листи підуть у спам.
   - `mail_mode`:
     - `mail` — як у твоєму CMS (PHP `mail()`), найпростіше;
     - `smtp` — надійніше: заповни `smtp.host / port / user / pass`
       (для Hostinger: `smtp.hostinger.com`, порт `465`, `ssl`);
     - `log` — листи не надсилаються, код пишеться в `data/mail.log`
       (зручно перевірити, що все працює).
3. Потрібен PHP 8.0+ з розширенням `pdo_sqlite` (є майже на всіх хостингах).
4. Відкрий `https://bilohash.com/games/too_much/api/game.php?a=ping` —
   має показати `{"ok":true,"v":1}`. Якщо `not_configured` — перевір `config.php`.

Папка `data/` має бути доступна PHP для запису (права 750/755).
Ще безпечніше — вказати в `config.php` `data_dir` поза `public_html`.

## 3. Як працює вхід

1. Гравець вводить email → приходить лист із 6-значним кодом і кнопкою «Увійти в гру».
2. Можна ввести код у грі або натиснути кнопку — гра відкриється вже з входом.
3. Код і посилання діють 15 хвилин і спрацьовують один раз; на код — 5 спроб.
4. Обмеження: 1 лист на хвилину і 6 на годину на адресу, 20 на годину з однієї IP.
5. Проходження кампанії, чемпіони, обраний боєць, мова, арена й складність
   зберігаються в акаунті й підтягуються на будь-якому пристрої.

## 4. Мови

Українська, English, Norsk — меню з прапорами у правому верхньому куті
та в паузі. Можна відкрити одразу потрібною мовою: `?lang=en`, `?lang=no`.

## 5. Онлайн-бій

Онлайн-кімнати (QR-код / код друга) працюють лише у версії на claude.ai —
на власному хостингу ці кнопки ховаються автоматично.
